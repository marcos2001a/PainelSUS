# Executar o painel no Linux

## Instalação

O instalador identifica Debian/Ubuntu e derivados, Fedora/RHEL e Arch Linux.
Ele instala Python 3.12 quando disponível (ou 3.13), cria `.venv` e instala
as dependências listadas em `requirements.txt`.

Na pasta do projeto, execute:

```bash
bash install/install.sh
```

O instalador usa `sudo` para instalar dependências do sistema, quando
necessário. Em Debian/Ubuntu, se os repositórios da distribuição não fornecerem
Python 3.12 ou 3.13, habilite um repositório que forneça uma dessas versões e
execute o instalador novamente.

## Iniciar, parar e reiniciar

```bash
bash install/start.sh
bash install/stop.sh
bash install/restart.sh
```

O servidor fica vinculado a `127.0.0.1:8000`. Acesse
`http://127.0.0.1:8000` no próprio computador. Os logs e o PID ficam em
`data/dashboard.log` e `data/dashboard.pid`.

Para acompanhar o log:

```bash
tail -f data/dashboard.log
```

Não exponha diretamente o servidor à rede. A documentação principal descreve
os requisitos adicionais para acesso remoto.
