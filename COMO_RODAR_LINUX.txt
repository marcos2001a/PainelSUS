## 1. Requisitos Mínimos do Sistema
- Distribuição Linux moderna (Ubuntu, Debian, Fedora, Arch Linux, etc.)
- Python 3.12 ou superior
- Kernel 4.15 ou superior (para algumas funcionalidades)
- Conexão com a internet (para instalar dependências)

## 2. Instalação de Dependências do Sistema (Ubuntu/Debian)
```bash
# Atualizar índice de pacotes
sudo apt update

# Instalar Python e pip (se não estiverem instalados)
sudo apt install -y python3 python3-pip python3-venv python3-dev build-essential

# Instalar dependências adicionais (se necessário)
sudo apt install -y libpq-dev  # Para PostgreSQL
sudo apt install -y libxml2-dev libxslt1-dev  # Para processamento XML/DCFS
```

## 3. Instalação de Dependências (Fedora/CentOS/RHEL)
```bash
# Atualizar sistema
sudo dnf update

# Instalar Python e pip (se necessário)
sudo dnf install -y python3 python3-pip python3-venv python3-devel

# Instalar dependências adicionais (se necessário)
sudo dnf install -y postgresql-devel libxml2-devel libxslt1-devel
```

## 4. Instalação de Dependências (Arch Linux)
```bash
# Atualizar sistema
sudo pacman -Syu

# Instalar Python e pip
sudo pacman -S python python-pip python-venv

# Instalar dependências adicionais (se necessário)
sudo pacman -S postgresql libxml2 libxslt
```

## 11. Iniciar o Servidor Linux
```bash
# Método 1: Comando direto
echo "Para iniciar a aplicação, execute:"
echo "  source .venv/bin/activate && python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000"

# Executar diretamente (em primeiro plano)
source .venv/bin/activate
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# Método 2: Usando script de serviço systemd (recomendado para produção)
cat > dashboard.service << 'EOF'
[Unit]
Description=Painel de Produção Ambulatorial
After=network.target

[Service]
Type=simple
User=$(whoami)
WorkingDirectory=$(pwd)
Environment="PATH=$(pwd)/.venv/bin"
ExecStart=$(pwd)/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# Instalar serviço systemd
sudo cp dashboard.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable dashboard
sudo systemctl start dashboard

# Verificar status
sudo systemctl status dashboard
```

## 12. Iniciar com Gerenciamento de Processos
```bash
# Usando nohup (manter rodando em background)
nohup source .venv/bin/activate && python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 > dashboard.log 2>&1 &

# Verificar processo em background
ps aux | grep dashboard

# Parar processo
pkill -f "uvicorn app.main:app"
```

## 13. Script de Inicialização Completo
```bash
#!/bin/bash
# script-de-inicializacao-dashboard.sh

# Configurações
HOST="0.0.0.0"
PORT="8000"
VENV_DIR=".venv"
LOG_FILE="dashboard.log"

# Cores para output (opcional)
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

# Função para exibir mensagens
function log() {
    echo -e "${GREEN}[$(date '+%Y-%m-%d %H:%M:%S')]${NC} $1"
}

# Função para exibir erros
function error_log() {
    echo -e "${RED}[$(date '+%Y-%m-%d %H:%M:%S')] ERRO:${NC} $1" >&2
}

# Iniciar ambiente virtual
if [ -f "$VENV_DIR/bin/activate" ]; then
    source "$VENV_DIR/bin/activate"
    log "Ambiente virtual ativado"
else
    error_log "Ambiente virtual não encontrado em $VENV_DIR"
    exit 1
fi

# Verificar se Python está disponível
if ! command -v python3 &> /dev/null; then
    error_log "Python3 não encontrado"
    exit 1
fi

# Iniciar servidor
log "Iniciando servidor na porta $PORT"
log "Abra seu navegador e acesse: http://localhost:$PORT ou http://<IP_do_servidor>:$PORT"

# Iniciar uvicorn
echo "source .venv/bin/activate && python3 -m uvicorn app.main:app --host $HOST --port $PORT" >> "$LOG_FILE"

nohup source .venv/bin/activate && python3 -m uvicorn app.main:app --host "$HOST" --port "$PORT" >> "$LOG_FILE" 2>&1 &

# Salvar PID
echo $! > dashboard.pid

log "Servidor iniciado com PID $(cat dashboard.pid)"
log "Logs disponíveis em: $(pwd)/$LOG_FILE"
log "Para parar o servidor: kill $(cat dashboard.pid) ou ./stop.sh"

# Criar script de parada
cat > stop.sh << 'EOF'
#!/bin/bash
if [ -f dashboard.pid ]; then
    pid=$(cat dashboard.pid)
    if kill -0 $pid 2>/dev/null; then
        kill $pid
        echo "Servidor parado (PID: $pid)"
    else
        echo "Servidor não está rodando"
    fi
    rm -f dashboard.pid
else
    echo "Arquivo PID não encontrado"
fi
EOF

chmod +x stop.sh
```

## 18. Solução de Problemas Específicos do Linux

### Problema: "Erro: módulo não encontrado: uvicorn"
```bash
sudo apt install -y python3-uvicorn  # Ubuntu/Debian
sudo dnf install -y uvicorn  # Fedora/CentOS
sudo pacman -S uvicorn  # Arch Linux
```

### Problema: "Erro de permissão de diretório"
```bash
# Corrigir permissões
sudo chown -R $(whoami):$(whoami) .
chmod -R 755 .
```

### Problema: "Porta 8000 já em uso"
```bash
# Encontrar processo na porta 8000
sudo lsof -i :8000

# Matar processo
sudo kill $(sudo lsof -t -i :8000)
```

## 19. Configurações Específicas de Ambiente

### Usando Dockerr (alternativa ao systemd)
```bash
# Construir imagem Docker
docker build -t dashboard-app .

# Executar container
docker run -d -p 8000:8000 --name dashboard dashboard-app

# Acessar logs
docker logs -f dashboard

# Parar container
docker stop dashboard
```

### Usando Systemd User (para home users)
```bash
# Criar diretório de configuração do usuário
mkdir -p ~/.config/systemd/user

# Copiar serviço para usuário
sudo cp dashboard.service ~/.config/systemd/user/
sudo systemctl --user daemon-reload
sudo systemctl --user enable dashboard
sudo systemctl --user start dashboard
```
